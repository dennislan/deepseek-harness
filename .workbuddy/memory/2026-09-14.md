# 2026-09-14

## native-macos「检查更新」提示卡优化

目标：菜单「检查更新…」右上角提示卡。原实现点击即弹「正在检查更新…」，安装期间提示还会被各安装步骤文字覆盖。

变更 `native-macos/App/Update/RuntimeUpdater.swift`：

- 删除检查中的「正在检查更新…」提示；`progressLabel` 的 `.checking` 文案改为「检查新版本」（仅用于"运行中再次点击"场景）。
- 新增 `BannerStyle.available`，并补 `CustomStringConvertible`（否则 `os.Logger` 插值编译报错，这是工作区里之前遗留的编译错误）。
- 发现新版本时用 `setReport`（不自动消失）显示「发现新版本 <version>，是否更新？」；`stage` 的安装步骤只写日志，不再覆盖提示。
- `stage(version:)` 去掉 `reportsToUser` 参数，收尾 `settle` 上移到 `performCheck`；成功 / 已是最新统一 `.success`（绿色对号），失败仍 `.failure`。

其他文件：

- `App/App/ContentView.swift`：`UpdateBanner` 增加 `.available` 图标 `arrow.down.circle.fill`，色值 #2563EB（app 主色，避免与绿勾混淆）。
- `Tests/RuntimeUpdaterManualPathTests.swift`：轮询首条提示，断言含「发现新版本」「是否更新」，并断言安装期间提示不变。
- `README.md` / `README.zh.md` 的「运行时更新」段落同步；`README.i18n.yaml` 用 `node_modules/.bin/tsx scripts/verify-translation-pairing.ts --write native-macos/README.md` 重新记录哈希。

## 本仓库 native-macos 验证要点

- 本机 PATH 上没有 `pnpm`，直接跑 `node_modules/.bin/tsx <script>`。
- 全量类型检查：`xcrun swiftc -typecheck -parse-as-library native-macos/App/{App,Update,Server,NativeBridge}/*.swift`。
- 离线断言：`bash native-macos/Scripts/test-updater-logic.sh`。
- 联网端到端：`bash native-macos/Scripts/test-updater-manual-path.sh`，约 1 分 20 秒；必须先 `mkdir -p native-macos/.build`，否则链接报 `errno=2`（`.build` 被 gitignore，干净 checkout 里不存在）。
